# Bright Coffee Shop Sales Analysis

## 1. Project Overview
This project focuses on analysing historical sales data for a coffee shop business. It examines sales performance across products, product categories, store locations and time periods to identify trends and patterns that can provide meaningful business insights.

The dataset contains 149,116 sales records covering the period from 1 January 2023 to 30 June 2023.

## 2. Project Objectives

- Analyse sales performance across different product categories and products.
- Compare sales performance across store locations.
- Examine sales trends by date, month and time of day.
- Identify the highest and lowest revenue-generating products and categories.
- Generate insights that can support informed business decisions.

## 3. Project Process
The project follows the following stages:

1. **Data Acquisition:** Obtained the original Bright Coffee Shop sales dataset in CSV format.
2. **Data Ingestion:** Uploaded the dataset into Databricks and created the project catalog, schema and raw table.
3. **Data Validation:** Used SQL queries to check data quality, missing values and data types.
4. **Data Analysis:** Used SQL to investigate sales performance and answer the CEO's business questions.
5. **Data Visualisation:** Used Excel PivotTables and charts to analyse and present sales performance.
6. **Project Planning:** Used Miro to create project flowcharts and Excel to track project progress using a Gantt chart.
7. **Documentation:** Organised project files and analysis outputs in GitHub.

## 4. Key Findings
The analysis highlighted several sales patterns:

- Coffee generated the highest revenue among the product categories.
- Hell's Kitchen generated more revenue than Lower Manhattan.
- Lower Manhattan recorded higher sales quantities, showing that higher sales volume does not always mean higher revenue.
- Sales revenue increased towards the end of the six-month reporting period, with June recording the highest monthly revenue.

## 5. Tools Used

- **Databricks SQL:** Data ingestion, validation and sales analysis.
- **Microsoft Excel:** Sales analysis, PivotTables, charts, project scheduling and Gantt chart.
- **Miro:** Project architecture and process flowcharts.
- **GitHub:** Project documentation and portfolio management.

## 7. Project Outcome

This case study provided practical experience in using data analytics tools to investigate business performance, identify sales patterns and communicate findings.
It demonstrates how data can be used to answer business questions and support informed decision-making.
